# حزم — مدير حزم لغة Niva

مدير حزم خاص بلغة البرمجة العربية **Niva** — لا يعتمد على أي مدير حزم خارجي.
يثبّت مكتبات Niva، وينشئ المشاريع ويديرها، ويحدّث المكتبات، ويحل تعارضات
الاعتماديات، ويعمل دون إنترنت للحزم المحفوظة محليا.

الحزمة برنامج مستقل مكتوب كله بلغة Niva، يعمل في بيئة Niva، ولا يدخل نظام
Niva أبدا — لا محرك ولا مكتبة أصلية. والمدير نفسه مكتوب بلغة Niva كاملة،
وRust مقتصر على بيئة تشغيل اللغة نفسها.

الخطوة 4 تبني: إنشاء مشروع (`حزم جديد` بقوالب أداة/مكتبة/فارغ)،
وإدارة اعتمادياته (`حزم أضف`/`حزم احذف`/`حزم تحديث`)، وتثبيته من
القفل حرفيا (`حزم تثبيت`)، وبناءه وتشغيله واختباره (`حزم ابن`/
`حزم شغل`/`حزم اختبر`)، وأمر `تحقق` (تطابق الشجرة المثبّتة مع القفل
اسما وإصدارا وبصمة — ويجريه `حزم شغل` قبل كل تشغيل)، والعزل الصارم
(الاستيراد فقط لما أُعلن في البيان)، و`حزم اعرض` شجرة، و`حزم لماذا`
(سلسلة الاعتماديات إلى حزمة بعينها). والثقة: بلا بصمة مسجلة لا تثبيت،
ولا مخرج صامت أبدا عند عدم تطابق بصمة — بلا علامة تجاوز وبلا تثبيت
جزئي. وأسماء الحزم بلا شرطة `-` أبدا (الفاصل `_`).

## البناء والتشغيل

```sh
# 1 — تمهيد بيئة التشغيل (ينزّل ثنائي Niva المثبّت دون استنساخ مستودع اللغة)
sh tools/تمهيد.sh

# 2 — فحص دخان: تحميل الوحدات ونسخة المحرك
نيفا src/رئيسي.نيفا

# 3 — شغّل الاختبارات (كل اختبار في الوضعين: المترجم والمفسر)
sh tools/شغّل-الاختبارات.sh
```

لا حاجة لاستنساخ مستودع لغة Niva كاملا. التمهيد ينزّل ثنائي Runtime المثبّت
من إصدارات مستودع `RIO4140/niva` (انظر `RUNTIME-COMPAT`).

## ملف البيان

كل حزمة مجلد فيه ملف `بيان.حزمة` — ملف بيانات نصي يُقرأ ولا يُنفَّذ أبدا:

```
اسم: أداة_مثال
إصدار: 1.0.0
وصف: وصف قصير بالعربي
دخول: مصدر/رئيسي.نيفا
نسخة_نيفا: 1.0.0
اعتماديات:
  حزمة_أ 1.2.3
  حزمة_ب ^2.0
اعتماديات_التطوير:
  حزمة_اختبار 0.1.0
```

- `نسخة_نيفا`: أدنى نسخة لغة تعمل معها الحزمة — والمحرك الأقدم مرفوض بخطأ عربي.
- `اعتماديات_التطوير`: للاختبار فقط — لا تُصدَّر ولا تُثبَّت للمستخدم.

## ملف القفل

`قفل.حزمة` يولَّد آليا وحده — لا يحرره الإنسان بيده. سطر لكل حزمة في الشجرة
بما فيها المتعدية، مرتبة بالاسم، بصيغة `اسم إصدار مصدر بصمة`:

```
# قفل حزم — يولَّد آليا؛ لا تحرره بيدك
حزمة_أ 1.2.3 github.com/مالك/حزمة_أ 9f2c…
```

القفل هو مصدر الحقيقة للنسخ القابلة للتكرار؛ وإن اختلف البيان والقفل رفض
التركيب بخطأ عربي («البيان والقفل مختلفان — شغّل حزم تحديث»).

## القواعد

- كل شيء بالعربي بشكل كامل: أسماء الملفات والمفاتيح والأوامر والرسائل.
- البيان يُقرأ ولا يُنفَّذ أبدا — فلا كود يعمل وقت التثبيت.
- لا تثبيت إلا لملفات `.نيفا`: بلا ثنائيات أجنبية، وبلا أدوات نظام.
- سقف 5 ميبيبايت للملف الواحد، وسقف 1 غيغابايت للمخزن العام.
- لا كتابة فوق مثبَّت بلا رفض صريح، ولا تثبيت صامت لإصدار مختلف.
- لا انتقال لخطوة تالية قبل نجاح اختبارات الخطوة السابقة في الوضعين.
